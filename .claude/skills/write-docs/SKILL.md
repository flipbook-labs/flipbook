# Write Docs

Flipbook's documentation is a plain Docusaurus site under `docs/`. Follow the shared `org/writing-style` skill for voice and banned patterns.

## Where pages live

- Pages are `.md` or `.mdx` files under `docs/docs/`, grouped by folder: `creating-stories/`, `frameworks/`, `contributing/`, `migration-guides/`, plus top-level `intro.md` and `install.md`.
- `docs/sidebars.ts` controls navigation. The Stories section lists pages by id, for example `creating-stories/controls`. The Frameworks and Contributing sections are autogenerated from their folders, so a new page there appears on its own. A new page in any other folder needs an entry in `sidebars.ts`.
- `docs/docusaurus.config.ts` sets `onBrokenLinks: 'throw'`, so a broken internal link fails the build.

## Code samples

Use `.mdx` for pages that embed code from the repo. Import the file with raw-loader and render it in a `CodeBlock`:

```mdx
import CodeBlock from "@theme/CodeBlock";
import ReactButton from "!!raw-loader!@site/../workspace/code-samples/src/React/ReactButton.luau";

<CodeBlock language="lua" title="Project/ReactButton.luau">
	{ReactButton}
</CodeBlock>
```

Put samples in `workspace/code-samples` so they stay real files that the repo can check. Look at `docs/docs/frameworks/react.mdx` for the tabbed pattern. Inline short snippets of a few lines instead.

## Check every claim

Never describe behavior you have not confirmed in source. Before you write about a feature, read the code under `workspace/` and any tests for it, and read the existing page if you are editing one. If you cannot find the source for a claim, leave it out and tell the user.

## Check the build

Preview with `lute run serve-docs`, which installs and starts the site from `docs/`. For structural changes, run `npm run build` inside `docs/` to catch broken links.

## Re-verify

**Re-verify these claims when this skill next loads.** Run these from the repo root. A command that fails or prints nothing means the skill needs updating:

```sh
grep -n onBrokenLinks docs/docusaurus.config.ts
ls docs/docs docs/sidebars.ts .lute/serve-docs.luau
```
