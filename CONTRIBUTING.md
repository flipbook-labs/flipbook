# Contributing to Flipbook

Flipbook welcomes focused bug fixes, features, tests, documentation, and tooling improvements. Start with the contributor [onboarding guide](docs/docs/contributing/onboarding.md) and use the commands and project conventions in [AGENTS.md](AGENTS.md).

Every change merges through a pull request. Read the [merge policy](.github/MERGE_POLICY.md) before choosing a scope or requesting review, and keep the repository's pull request template intact.

Application changes require a human review from the application owners. Engine changes use Greptile and the required automated checks without a mandatory human approval. Mixed changes follow both paths.
