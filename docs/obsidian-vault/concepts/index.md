# Concepts

Core concepts that underpin how Flipbook works.

- [Story](./story.md): A ModuleScript that returns a renderable definition
- [Storybook](./storybook.md): Tells Flipbook where to discover stories and how to render them
- [ModuleLoader](./module-loader.md): The sandboxing layer that isolates story execution
- [Storyteller](./storyteller.md): The backbone library for story discovery and rendering
- [React](./react.md): Roblox's Luau port of React 17
- [Fusion](./fusion.md): dphfox's reactive UI library for Luau
- [Roact](./roact.md): Roblox's legacy declarative UI library
- [Storybook.js](./storybook-js.md): The JavaScript library that inspired Flipbook
- [Hoarcekat](./hoarcekat.md): The story plugin whose format Flipbook still renders
- [UI Labs](./ui-labs.md): Another Roblox storybook plugin whose controls Flipbook migrates
