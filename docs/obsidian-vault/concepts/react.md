# React

When we talk about React we usually mean the [Luau port that Roblox maintains](http://github.com/roblox/react-luau). Flipbook itself depends on the [jsdotlua](https://github.com/jsdotlua/react-lua) distribution of the port, which tracks React 17, and any compatible React package works in your own Stories. See [[usage/frameworks/react]] for how to use it with Flipbook.
