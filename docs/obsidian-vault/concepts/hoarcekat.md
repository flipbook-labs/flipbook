# Hoarcekat

Hoarcekat > Horsecat > Llama

[Hoarcekat](https://github.com/Kampfkarren/hoarcekat) is Kampfkarren's story plugin for Roblox and one of Flipbook's main [[README#Inspirations|inspirations]]. Its stories are modules that return a `function(target)` which mounts UI and returns its own cleanup callback.

Flipbook renders that shape natively, so Hoarcekat stories keep working when you switch. The differences that do require attention are covered in [[usage/migration-guides/migrating-hoarcekat|Migrating from Hoarcekat]].
