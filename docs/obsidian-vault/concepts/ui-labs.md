# UI Labs

[UI Labs](https://github.com/PepeElToro41/ui-labs) is another storybook plugin for Roblox, with its own story format and a rich control schema.

Flipbook automatically migrates controls written in UI Labs' schema when it loads a Story, so stories authored for UI Labs keep their controls without changes. See [[usage/migration-guides/migrating-ui-labs|Migrating from UI Labs]] for the control mapping and how to convert a story to Flipbook's format.
