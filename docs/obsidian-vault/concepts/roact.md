# Roact

[Roact](https://github.com/roblox/roact) is Roblox's original declarative UI library, a Lua implementation of the React API. The repository is archived and we consider it legacy software: use [[concepts/react|React]] for new work.

Flipbook continues to render Roact Stories for projects that already use it. See [[usage/frameworks/roact|the Roact framework guide]] for the setup and what the legacy status means for support.
