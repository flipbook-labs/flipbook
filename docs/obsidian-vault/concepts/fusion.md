# Fusion

[Fusion](https://github.com/dphfox/Fusion) is a reactive UI library for Luau by dphfox. Instead of re-rendering components, UI built with Fusion updates through observable state objects that push changes directly to instance properties.

Flipbook has native support for rendering Fusion Stories: supply Fusion through your Storybook's `packages` and every Story under it renders with it. See [[usage/frameworks/fusion|the Fusion framework guide]] for the setup and a complete example.
